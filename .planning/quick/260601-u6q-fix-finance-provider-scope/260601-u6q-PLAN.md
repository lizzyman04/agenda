# Quick Task 260601-u6q: Fix `_dependents.isEmpty` crash on finance form open

## Problem

Opening any finance form (Transaction, Debt, Recurring) crashes with:

```
package:flutter/src/widgets/framework.dart: Failed assertion line 6268 pos 12: _dependents.isEmpty: is not true
```

## Root Cause

`FinanceDashboardScreen` hosts the 6 finance cubits in a `MultiBlocProvider`.
That screen is kept permanently mounted by the `IndexedStack` in `_AppShell`.
The list screens push their form routes wrapped in `BlocProvider.value`, re-providing
the *same* cubit instance a second time at the root Navigator level:

```dart
builder: (_) => BlocProvider.value(
  value: context.read<TransactionCubit>(),
  child: TransactionFormScreen(...),
),
```

One bloc instance is now provided by two live `InheritedProvider` elements. During the
route push/pop transition the framework deactivates an `InheritedElement` while
`BlocBuilder` dependents from the still-mounted dashboard subtree remain registered →
the `_dependents.isEmpty` assertion fires.

Hoisting the provider *inside* the finance screen (prior attempt) did not help because
the dual-provision across the route boundary remained.

## Fix Strategy

Provide the 6 finance cubits **above `MaterialApp`** (above the Navigator) so every
pushed route inherits them through normal `InheritedWidget` lookup — eliminating the
need to re-provide via `BlocProvider.value`.

Note: `MaterialApp.home` sits *below* the Navigator, so providers placed there are NOT
inherited by pushed routes. The providers must wrap `MaterialApp` itself.
