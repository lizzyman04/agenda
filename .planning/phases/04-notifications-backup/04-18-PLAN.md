<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App sandbox -> OS cloud backup (iCloud / iTunes) | Plaintext finance data crosses to Apple servers or a desktop backup unless excluded. |
| Source tree -> future storage roots | A later change that writes user data under a non-excluded root silently reopens the leak. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-04-18-01 | Information disclosure | Isar database and `<Documents>/backups` plaintext safety copies uploaded by iOS backup | critical | mitigate | AppDelegate.excludeUserDataFromBackup sets isExcludedFromBackup on the Documents directory and `backups` at every launch; contract test pins it. Device check stays in 04-VERIFICATION.md. |
| T-04-18-02 | Information disclosure | New persistent storage root added later (Application Support, Library, external storage) | high | mitigate | Contract case 6 fails on any such path_provider call until the exclusion is extended. |
| T-04-18-03 | Denial of service | Native exclusion code blocking or crashing app launch | low | mitigate | Every filesystem call uses `try?`; the method returns early when the Documents URL is missing. |
| T-04-18-04 | Repudiation | Privacy note claims cloud backup is off while only Android was excluded | medium | mitigate | backupReinstallNote now describes both platforms and is only accurate with Task 1 in place; both land in this plan. |
</threat_model>
