<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App -> user-chosen storage location | Plaintext backups land wherever the user saves them via the system dialog. |
| File picker -> app (import side, used by 04-17) | Picked content is untrusted; sizes are checked before reading. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-04-16-01 | Information disclosure | Plaintext backup in shared storage | medium | accept | Stated on screen (backupPrivacyNote); location is the user's explicit choice; no sharing intent, no network (D-12). |
| T-04-16-02 | Denial of service | Importing a multi-hundred-megabyte file into memory | medium | mitigate | Gateway checks PlatformFile.size against the 25 MiB cap before reading bytes and reads from the cache path instead of loading data in the picker. |
| T-04-16-03 | Tampering | Path built from a picked file name | medium | mitigate | Picked names are only passed through to labels; paths come from the plugin's cache path; safety backups use generated names (04-11). |
</threat_model>
