// PieChart
PieChart(
  PieChartData(
    sections: categorySpends.entries.map((e) => PieChartSectionData(
      value: e.value / 100.0,   // int cents → double for chart only
      title: '',                // no in-slice text; use legend below
      color: _categoryColor(e.key),
      radius: 64,
    )).toList(),
    centerSpaceRadius: 48,     // donut
    sectionsSpace: 2,
  ),

// BarChart
BarChart(
  BarChartData(
    barGroups: indexedEntries.map((entry) => BarChartGroupData(
      x: entry.index,
      barRods: [BarChartRodData(
        toY: entry.spentCents / 100.0,
        color: _categoryColor(entry.categoryId),
        width: 20,
        borderRadius: BorderRadius.vertical(top: Radius.circular(4)),
      )],
    )).toList(),
    titlesData: FlTitlesData(
      bottomTitles: AxisTitles(sideTitles: SideTitles(
        showTitles: true,
        reservedSize: 36,
        getTitlesWidget: (value, _) => Text(shortName, style: TextStyle(fontSize: 10)),
      )),
      leftTitles: AxisTitles(sideTitles: SideTitles(showTitles: false)),
      topTitles: AxisTitles(sideTitles: SideTitles(showTitles: false)),
      rightTitles: AxisTitles(sideTitles: SideTitles(showTitles: false)),

    gridData: FlGridData(show: false),

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HomeDashboardCubit state → UI display | Computed values (balance, net worth, categorySpend) rendered to screen |
| SharedPreferences → currency symbol | Currency symbol read from device storage for display |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05-01 | Tampering | fl_chart double conversion (amountCents / 100.0) | accept | Double conversion is display-only — never stored, never fed back into business logic. Chart values are read-only visual representation. |
| T-03-05-02 | Information Disclosure | Balance/net worth displayed on screen | accept | Local app — only the device owner sees the screen. No network transmission. Privacy constraint (DATA-01) satisfied. |
| T-03-05-03 | Tampering | SharedPreferences userCurrency — could theoretically be modified by root user | accept | Currency symbol is display metadata only (e.g., "MT"). Modifying it affects display only — no financial calculation changes. ASVS L1 does not require crypto protection of display preferences. |
| T-03-05-04 | Denial of Service | fl_chart PieChart with empty sections list | mitigate | Guard: if categorySpend.isEmpty, render text message instead of PieChart widget. Test coverage verifies this path (Pitfall A2 from RESEARCH.md). |
| T-03-05-05 | Tampering | Month navigation — user can navigate arbitrarily far back | accept | D-10 explicitly allows unlimited backward navigation. No security risk — reads historical data already stored. |
</threat_model>
