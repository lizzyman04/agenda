## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Path change silently unsorted 2 import blocks, adding 4 new `directives_ordering` lints**

- **Found during:** Task 2, post-rewrite `flutter analyze`
- **Issue:** Same mechanism 06-16 hit. Renaming `data/finance/savings_goal_dao.dart` → `data/finance/goal/savings_goal_dao.dart` changes the string's sort key, so previously-alphabetical import blocks in `lib/config/di/finance_module.dart` and `lib/main.dart` were no longer sorted. - **Files modified:** 2
- **Commit:** `7f13fb5`

### Scope Clarification (not a code deviation)

**2. The execution brief's objective sentence was ambiguous about `infrastructure/`**

The brief said to nest "`lib/data/finance/` … plus the related infrastructure files and `finance_module.dart` into the same six per-entity subfolders". **That is not what the PLAN says, and it would have been wrong.** `lib/infrastructure/finance/` holds exactly 6 hand-written files — well under the 10-file cap, not a violation, and not something the guard asks anyone to touch. The PLAN's Task 1 moves only `data/finance` files; it lists the six `*_repository_impl.dart` files and `finance_module.dart` in `files_modified` because they are **import-repoint targets**, and its `artifacts` block names only `lib/data/finance/<entity>/<model>.dart` paths. 06-16 likewise left `infrastructure/` flat. I followed the PLAN: `infrastructure/finance/` is unchanged in layout, and only its import lines were rewritten. Flagging it rather than silently working around it, per the brief's own instruction.

### Non-deviations worth recording

- The `.g.dart` pairing needed **no** content edit. Every `part 'x_model.g.dart';` / `part of 'x_model.dart';` directive is a bare relative filename, so co-moving model and companion in one `git mv` kept them paired; `build_runner` regenerated all six identically (they did not even show as modified in `git status`).
- The known pre-existing PT-BR amount-parsing bug in `lib/core/utils/amount_parser.dart` (STATE.md Blockers) was **not** touched, as instructed.
