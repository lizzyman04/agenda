<objective>
Extend the lock from cold start to every return from the background (D-01, D-02), hide app
content in the app switcher with the privacy overlay (D-04, Flutter half), and keep
app-initiated excursions from relocking (D-03). Thin path first: background past the timeout ->
resume -> lock screen with no content frame, with the overlay painted on inactive.

Purpose: SC-1/SC-2 cover a phone left unattended mid-use, not only a cold start; and a lock that
fires after every file pick or permission prompt would be unusable.

Output: lifecycle methods on AppLockCubit, LockGate lifecycle listener and overlay layer,
PrivacyOverlay, ExcursionGuard (domain + impl) wrapped around the five Phase 4 external-UI
calls, tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App -> OS app switcher | The OS snapshots the app for the recents/App Switcher view. |
| App -> external UI (picker, permission, settings) | Control leaves the app on purpose and returns. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-22 | Information disclosure | App-switcher snapshot showing tasks/finances | high | mitigate | PrivacyOverlay painted on inactive while frames still run (PIN on); native backstops follow in 05-10; widget test asserts the overlay after inactive + pump. |
| T-05-23 | Denial of service | Relock loop after picker, permission or biometric trips | medium | mitigate | Locking is decided only on hidden; app-initiated trips are wrapped in ExcursionGuard; pinned by lifecycle and guard tests. |
| T-05-24 | Elevation of privilege | Excursion window abused to keep the app unlocked | medium | mitigate | Excursion trips lock once elapsed reaches max(timeout, 300 s); pinned by app_lock_lifecycle_test. |
| T-05-25 | Information disclosure | A content frame between overlay removal and lock | high | mitigate | onResumed emits obscured false and locked true in one state; test asserts exactly one emission. |
